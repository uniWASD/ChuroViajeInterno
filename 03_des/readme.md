# 03_des - Análisis y Diseño (Design)

Aquí se define cómo se construirá el sistema técnicamente, mapeando los requisitos a una solución de software. 

### ¿Qué archivos deben subirse aquí?
*   El documento de arquitectura detallando nuestro modelo distribuido cliente-servidor: Frontend móvil en Flutter, Backend de gestión en Java y Motor Core en C++.
*   Los Diagramas de Comportamiento UML asociados a las Especificaciones de Casos de Uso.
*   Los modelos relacionales de la base de datos y la documentación del diseño de endpoints REST.
*   El diseño de integración con el SDK de Mapbox para el renderizado del mapa.
