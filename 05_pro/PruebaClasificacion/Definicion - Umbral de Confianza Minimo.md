Aqui el Umbral Minimo se establece en 60% (UMBRAL_CONFIANZA = 0.60) evaluado mediante las probabilidades de predicción del modelo (predict_proba) y con respecto al que pasa si el modelo no esta seguro? Si la certeza del modelo para un mensaje es menor al 60% (< 0.60), el mensaje se considera ambiguo/no confiable, tambien el sistema no toma el mensaje como un reporte válido de combustible y lo clasifica automáticamente como "mensaje no relevante/ambiguo" (marcado con el motivo Baja confianza)
