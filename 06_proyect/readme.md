# 06_proyect - Gestión y Entorno (Project Management & Environment)

Organizacion del equipo, configuración de la infraestructura donde vivirá el sistema.

### ¿Qué archivos deben subirse aquí?
*   Cronogramas (Diagramas de Gantt), asignación de tareas y planes de las iteraciones RUP.
*   Archivos y scripts de configuración para el servidor VPS básico destinado a alojar el backend (Java), el motor core (C++) y la base de datos.
*   Configuraciones DNS asociadas al dominio web.
